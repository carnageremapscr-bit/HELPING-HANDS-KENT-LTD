# Helping Hands Kent Ltd - One Page Website

A branded one-page company website built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` - Main page layout and section content
- `styles.css` - Brand theme, responsive design, and animations
- `script.js` - Scroll reveal behavior and footer year
- `image-1772982025038.png` - Company logo asset

## Run Locally

Open `index.html` in VS Code Live Preview or any browser.

## Branding Notes

- Primary pink: `#e8347c`
- Primary green: `#06712f`
- Visual style: clean, friendly, premium domestic/commercial cleaning brand
